# proto-plugins

plugins for [proto](https://moonrepo.dev/proto)

## plugins

### perry

[perry](https://www.perryts.com/)

```bash
$ proto plugin add perry https://raw.githubusercontent.com/sasaplus1/proto-plugins/main/perry/plugin.toml
$ proto install perry
```

### tinygo

[tinygo](https://tinygo.org/)

```bash
$ proto plugin add tinygo https://raw.githubusercontent.com/sasaplus1/proto-plugins/main/tinygo/plugin.toml
$ proto install tinygo
```
